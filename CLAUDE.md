# Panduan untuk Claude di repo ini

Proyek ini adalah systematic literature review mengikuti PRISMA 2020.

- Gunakan skill `slr-prisma` untuk protokol, seleksi, dan diagram alir.
- Gunakan skill `academic-writing` untuk draf di `06-manuscript/`.
- Gunakan skill `academic-citation-manager` untuk `references/references.bib`.
- Gunakan Consensus untuk mencari paper; catat setiap pencarian di `02-search/search-log.md`.
- Jangan pernah mengarang referensi. Jika tidak yakin, tandai `[CITATION NEEDED]`.
- Gaya sitasi: APA 7. Bahasa manuskrip: ikuti `README.md`.
